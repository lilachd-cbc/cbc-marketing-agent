# מחולל עלונים

התבנית משתמשת ב־Heebo בלבד: כותרות 900, הדגשות 700 וטקסט 300. עברית RTL, תאריכים, שעות ופרטי קשר מבודדים בכיווניות LTR. הצבעים מזוהים לפי שם הקורס באמצעות themes.js. אין יצירת טקסט שיווקי או מבצעים שלא נמסרו בנתונים.

## שימוש

```sh
npm ci
node flyer/generate.js test-course.json --format a4 --output output/example-a4.jpg
node flyer/generate.js test-course.json --format square --output output/example-square.jpg
node flyer/generate.js test-course.json --format story --output output/example-story.jpg
node --test flyer/test.js
```

| פורמט | מידות JPG בפיקסלים |
| --- | --- |
| a4 (ברירת מחדל) | 2480×3508 |
| square | 1200×1200 |
| story | 1080×1920 |

A4 מתאים להדפסה ב־210×297 מ״מ בכ־300 פיקסלים לאינץ׳; אינו PDF לדפוס, אין גלישה/סימני חיתוך או CMYK. בסטורי נשמרים שוליים גדולים למעלה ולמטה עבור ממשק הרשת החברתית. deviceScaleFactor=1 מבטיח שמידות JPG זהות למידות המבוקשות.

החתימה הקיימת `generateFlyer(course, outputPath)` נשמרת; אפשר להוסיף ארגומנט שלישי `{ format: 'square', logoPath: '/path/to/logo.png' }`. ניתן גם להגדיר `format` ו־`logoPath` ב־JSON. אפשרויות CLI גוברות על ערכי JSON. נתיבי לוגו יחסיים נפתרים ביחס לתיקיית ההרצה; לוגו ברירת המחדל נפתר ביחס לתיקיית המחולל.

## הלוגו הרשמי

הלוגו שסופק ב־24.10.2026 נשמר ללא שינוי כ־`flyer/assets/cbc-logo.jpg` ומשולב אוטומטית בכל הפורמטים. קובץ JPEG המקורי כולל רקע בהיר; הוא לא נחתך, לא נמתח ולא הומר ללוגו חלופי.

אפשר לספק PNG, JPEG או WebP אחר באמצעות `--logo`. התמונה מוטמעת ב־HTML ומוצגת בשלמותה. אם קובץ ברירת המחדל חסר, נרשמת אזהרה והשטח נשאר ריק. נתיב מפורש חסר או תמונה פגומה גורמים לכישלון ההפקה. להפקות דפוס עתידיות עדיף מקור ברזולוציה גבוהה יותר, אם זמין.

## נתונים ובקרת איכות

`title` חובה. שדות התוכן הקיימים נתמכים: `subtitle`, `date`, `time`, `sessions`, `hours`, `location`, `instructor`, `audience`, `topics` (מערך מחרוזות), `promo`, `promoDeadline`, `label`. שדה `phone` אופציונלי. פרטים אופציונליים שלא נמסרו לא מומצאים. כל טקסט עובר escaping כדי שסימנים כגון & ו־< לא ישברו את התבנית.

מומלץ להזין כותרת קצרה, שורת משנה ו־3–4 נושאים קצרים. תוכן לא נחתך ולא מוסתר כדי שיתאים: חריגה מהשטח גורמת לשגיאה ומבקשת לקצר את הנתונים.

נדרשת גישה ל־fonts.googleapis.com ול־fonts.gstatic.com לטעינת Heebo. המחולל ממתין לטעינת המשקלים בעברית ובאנגלית ולפענוח הלוגו; אם הטעינה נכשלת לא נשמרת תמונה בגופן חלופי. הדפדפן נסגר גם בשגיאה, וה־CLI מחזיר קוד יציאה שאינו אפס.

קובצי `test-course.json`, `test-events.json`, `test-trade.json` מכילים נתוני בדיקה ישנים, כולל תאריכים ומבצעים. התמונות שנוצרות מהם הן דוגמאות לבדיקה בלבד, ואינן מיועדות לפרסום ללא עדכון ואישור הנתונים.
